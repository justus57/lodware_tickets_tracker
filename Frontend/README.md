# LODWARE Ticket Tracker — Frontend

Simple React (Vite) UI for the Mini Ticket Tracker.

## Setup

```bash
cd Frontend
npm install
npm run dev
```

App: `http://localhost:5173`

Make sure the backend is running on `http://localhost:3000`. Vite proxies `/tickets` to the API.

## Features

- Create a ticket
- List tickets with status and priority
- Filter by status
- Change ticket status
- Show counts by status
